# Guild Event Warp

> 画面右上の小さいボタンから封鎖戦マップの 1 チャンネルとギルドアジトにワープ

| 項目 | 内容 |
| --- | --- |
| キー | `guild_event_warp` |
| ソース | [guild_event_warp.lua](guild_event_warp.lua) |
| 設定画面 | なし（ボタン列の開閉のみ、状態は保存されます） |

## 使い方

ON にすると**画面右上**にボタンが 4 つ、左から次の順で並びます。

| アイコン | 行き先 | イベント ID |
| --- | --- | --- |
| ギルドアジト | 自ギルドのアジト | （なし） |
| ドラグーン | ギルドイベント「ドラグーン」のマップ | 500 |
| アラクネ姉妹 | ギルドイベント「アラクネ姉妹」のマップ | 501 |
| バウバス | ギルドイベント「バウバス」のマップ | 502 |

![画面右上に横一列で並ぶ 4 つの小さなボタン。左端がギルドアジト、続いてドラグーン・アラクネ姉妹・バウバスのアイコンで、右端に折りたたみ用の矢印ボタンが付く](images/01-buttons.png)

封鎖戦の 3 つはクリックするとそのマップへ移動し、**移動後に自動でチャンネル 1 へ
切り替えます**（すでに 1ch のときは切り替えません）。

**ギルドアジト**は経路が別で、ギルド活動 UI の「アジトへ移動」と同じ処理を呼びます。
アジトはギルドごとの専用マップなので、チャンネルの切り替えは行いません。
確認ダイアログは出さず、クリックで即移動します。

右端の矢印ボタンでボタン列を**折りたたみ／展開**できます。この状態は保存され、
次回ログイン時も維持されます。

## しくみ

* ボタンは `slot` にモンスタークラスの `Icon` を貼っただけのもので、
  クリックで `control.CustomCommand("MOVE_TO_ENTER_NPC", <イベントID>, 1, 0)` を呼びます。
  これはギルド活動 UI（`guild_activity_ui`）の封鎖線ランキング「移動」ボタンと同じ処理です。
* 移動前に**移動可否チェック**（`g.guild_event_warp_can_move`）を通します。
  次のいずれかに当てはまるときは `ThisLocalUseNot` を表示して移動しません。
  * 統合サーバー／PVP フィールド／PVP サーバーに居る
  * レイヤーが 0 以外（レイヤー変更中）
  * マップ種別が `Dungeon`
  * マップの `Keyword` に `IsRaidField` または `WeeklyBossMap` を含む
* 移動が成立するとフラグを立て、移動先マップでの初期化時に
  `RUN_GAMEEXIT_TIMER("Channel", 0)` でチャンネル 1 へ移動します。
* **ギルドアジト**のボタンだけは `guild.RequestGuildAgitMove()` を呼びます。
  これはギルド活動 UI の「アジトへ移動」ボタン
  （`EXEC_AGIT_MOVE_GUILD_ACTIVITY_DETAIL_AGIT_MOVE`）と同じ処理です。
  公式側もこの経路では移動可否チェックを持たない（可否はサーバーが判定する）ため、
  こちらも `g.guild_event_warp_can_move` は通しません。
  ギルドに所属していないときだけ、要求を出さずにメッセージを表示します。
  アイコン画像はギルド活動 UI のメニューと同じ `guild_activity_menu_GuildAgitMove` です。
* ボタン列のフレームは**レイヤー 31**（素の画面端の小さなボタン `minimized_*_button` と同じ）に
  置いています。土台の `notice_on_pc` はレイヤー指定が無く、そのままだとインベントリ
  （レイヤー 95）より手前に出るため、画面右上でインベントリと重なったとき**インベントリの
  上にボタンが描かれ、押すとワープしてしまう**ためです。
* アジトのアイコンは UI 用の画像で背景がくり抜かれているため、そのままだと下地が
  透けます。slot より先に `black_color` の `picture` を同じ位置・同じ大きさで敷いて
  黒背景にしています（同じ親では後から作った方が上に描かれるため）。
  この板は `EnableHitTest(0)` でクリックを拾わず、折りたたみでは slot と一緒に畳みます。
  モンスターアイコンは元から不透明なので敷いていません（`bg` を持つ項目だけ敷く）。

## 保存先

`../addons/_nexus_addons_p/<アカウントID>/guild_event_warp.json`

```json
{ "open": true }
```

`open` はボタン列を展開しているかどうかです。

## 注意

* 本家 Nexus Addons など、同名の旧初期化関数（`GUILDEVENTWARP_ON_INIT`）を持つ
  アドオンが読み込まれている場合は、競合を避けるため初期化をスキップします。
* 派生版では、旧クライアントの削除済み内部関数を呼んでいて移動できなかった不具合と、
  未知／インスタンスマップで可否チェックがエラーになりワープ機能全体が止まる不具合を
  修正済みです（v1.0.0）。
