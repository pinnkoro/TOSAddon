# バフ一覧（buff_list）

> PT メンバーのバフを、バフごとに表示 / 非表示できるようにする

| 項目 | 内容 |
| --- | --- |
| 設定キー | `party_buff`（一覧の中身は別ファイル） |
| ソース | [buff_list.lua](buff_list.lua) |
| 設定画面 | 「フレーム関連」セクション →「バフ一覧」ボタン |
| 保存先 | `../addons/_nexus_addons_p/<アカウントID>/mini_addons_buffs.lua` |

## 使い方

一覧ウィンドウでバフごとにチェックを付けると、そのバフを PT メンバーのバフ欄へ出します。

* 検索欄で絞り込めます。`全部ON` / `全部OFF` の**対象は「今見えている分」だけ**です。
* `バックアップ` で今のチェック状態を控え、`復元` でそこへ戻せます（控えは 1 つだけ。押すたびに上書き）。

## しくみ

* 一覧に出すバフの列挙は `Mini_addons_buff_list_each` **1 箇所に寄せてあります**。
  表示と一括操作で条件（Group1 / ShowIcon / TeamLevel 除外 / 検索語 / アイコン無しの除外）が
  分かれると、**見えているものと一括操作の対象が食い違い**、出ていないバフまで切り替わります。
* 反映は `ON_PARTYINFO_BUFFLIST_UPDATE` で行います。
* ウィンドウは ESC で閉じられます（`Mini_addons_buff_list_ESCAPE_PRESSED`）。

## 注意

* 保存先が `.json` ではなく `.lua` なのは読み込みの速さのためです。**書き込み側は必ず
  `Mini_addons_save_buffs` を通すこと**（`g.save_json` を直接呼ばない）。1 箇所でも json のまま
  残ると、次の読み込みが `.lua` を見つけられず旧 json へ落ち、初回ログインの数秒が戻ります。
* 控えが無いときの「戻す」は**何もしません**（黙って空で上書きしないこと）。
