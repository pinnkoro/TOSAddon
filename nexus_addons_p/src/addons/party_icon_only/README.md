# Party Icon Only

> パーティ情報を職業アイコンだけにして、クリック判定もアイコンの範囲だけにします

| 項目 | 内容 |
| --- | --- |
| キー | `party_icon_only` |
| ソース | [party_icon_only.lua](party_icon_only.lua) |
| 設定画面 | なし（アドオン一覧の ON/OFF のみ） |

## 使い方

ON にするだけです。画面左のパーティ情報（`partyinfo`）が、**小さな見出し（`PT`）＋
メンバーの職業アイコンを縦に並べた 50px 幅の列**になります。名前・HP/SP ゲージ・
レベル・バフ／デバフ欄は出ません。リーダーの印（`leader_img`）はアイコンの右上に残ります。

**この 50px 幅の外を押した入力は、素と同じように下の 3D 画面へ抜けます。**
アイコンの上での右クリック（メンバーのコンテキストメニュー）は素のまま使えます。

**位置を変えたいときは見出し（`PT` の帯）をドラッグ**してください。ここが掴み代です。
アイコンの上は当たり判定を持つので掴めません。

### 展開する / 格納する

**見出しの帯を右クリック**すると、切り替えのメニューが出ます。今の状態と逆のものだけが
並びます（格納中なら「展開する」、展開中なら「格納する」）。

* **格納**（既定）… アイコンだけの列。当たり判定もその範囲だけ
* **展開** … 素の見た目に戻ります。名前・HP/SP・レベル・バフ欄が出て、当たり判定も
  素どおり横 700px に戻ります。**Mini Addons の「パーティー情報フレームを小さくする」
  「パーティーメンバーの場所表示」も、展開中は普通に動きます**

アドオンを OFF にしなくても素の表示に戻せるので、「普段はアイコンだけ、必要なときだけ
全部見る」という使い方ができます。設定は `settings.json` に残るので、次回もそのままです。

**アイコンの上での右クリックは素のまま**です（メンバーのコンテキストメニューが出ます）。
切り替えのメニューが出るのは見出しの帯だけです。

OFF に戻すと、その場で素の見た目・大きさへ戻ります。

## なぜ必要か

素のパーティ情報は **1 人あたり横 700px の行**（controlset `partyinfo`）で、フレーム側も
`partyinfo.xml` の `<input ... hittestframe="true"/>`。名前もバフ欄も出ていない余白まで
含めた横 700px の帯がそのまま当たり判定になるため、**画面左側の広い範囲でクリックが
3D 画面へ抜けません**（そこを押しても移動も敵の選択もできない）。

このアドオンは行の中身をアイコンだけにしたうえで、controlset とフレームをアイコンと
同じ 50px 幅へ縮めます。**フレームの矩形＝アイコンの列そのもの**になるので、
見た目を減らすことと当たり判定を減らすことが同じ 1 つの操作になります。

## しくみ

0.5 秒間隔のタイマーと、`PARTY_UPDATE` / `PARTY_INST_UPDATE` / `PARTY_BUFFLIST_UPDATE` の
3 つのメッセージから `Party_icon_only_apply()` を呼び、次を行います。

1. `partyinfo` の子を頭から見て、`PTINFO_` で始まる行（controlset）と見出しを集める。
2. 行の中の子は、**`jobportrait_bg` と `leader_img` 以外をすべて隠す**。
   名指しで隠さず「残すものを列挙する」形にしてあるので、Mini Addons の
   「パーティーメンバーの場所表示」が足す `location<n>` のような、素の controlset に
   無い子も一緒に畳めます。
3. `jobportrait_bg` の margin を `0 0 0 0` にして左上へ寄せ、`leader_img` を右上へ
   寄せ直したうえで、行を 50x50 へ縮める（素の位置のままだと右が 3px はみ出て切れます）。
4. 見出し（`titlegbox`）を `50x26` の掴み代にして先頭に置き、その下へ行を 50px 間隔で
   積み直す（素の `PARTYINFO_CONTROLSET_AUTO_ALIGN` と同じく margin で動かします）。
5. `partyinfo` 自体を `50 x (26 + 行数 × 50)` へ縮める。

**見出しを残しているのは掴み代のためです。** ToS では「フレームの当たり判定がある範囲の
うち、当たり判定を持つコントロールが乗っていない場所」を押すとウィンドウを動かせます。
`titlegbox` は `hittestbox="false"` なので、ここを押すと下のフレームが受けて動かせます。
フレームをアイコンの列まで縮めると残りはアイコンで埋まってしまうため、**この帯が無いと
ウィンドウを動かす手段が無くなります**（フレームの当たり判定そのものを落とすと、
今度は掴めなくなるうえアイコンの上も押せなくなります）。

見出しの中のボタンは、**召喚獣 UI を持つクラス（素の `IS_NEED_SUMMON_UI()` が 1）**
では「パーティ情報 ⇄ 召喚獣情報」の切り替えになっています。出し入れは素に任せ、
こちらは出ているときに見出しの文字がその下へ潜らないよう幅を空けるだけにしています。

OFF にしたときは `Party_icon_only_restore()` が行（`PTINFO_`）を破棄して、素の
`ON_PARTYINFO_UPDATE` に組み立て直させます。隠した子や縮めた大きさを 1 つずつ
覚えて戻すのではなく素へ作らせているので、素の作りが変わっても戻し方が追従します。

## 保存先

なし（ON/OFF は `../addons/_nexus_addons_p/<アカウントID>/settings.json` に入ります）。

## 注意

* **動かせるのは見出し（`PT` の帯）を掴んだときだけ**です。アイコンの上は当たり判定を
  持つので掴めません。
* **展開中は当たり判定も素に戻ります。** アイコンだけにする目的で使っているなら、
  用が済んだら格納へ戻してください。
* Mini Addons の「パーティー情報フレームを小さくする」（`party_info`）と
  「パーティーメンバーの場所表示」（`pt_info`）は、**このアドオンが ON のあいだ
  自動的に何もしなくなります**（Mini Addons 側に待避の分岐を入れてあります）。
  設定を変える必要はありません。
  * 入れた理由: `Mini_addons_PARTY_BUFFLIST_UPDATE` は**「パーティー情報フレームを
    小さくする」が OFF のときも** `partyinfo` を素の幅（700px）へ戻し、しかも 5 秒ごとの
    更新から呼ばれます。こちらは 0.5 秒周期で畳み直すので、**表示は畳まれたままなのに
    アイコンの右と下に押せる帯が現れる**という形になっていました。
* Mini Addons の「PT バフの表示切替」（`party_buff`）は、バフ欄そのものが畳まれるため
  意味がなくなります（設定は残りますが表示に出ません）。
* 対象は画面左のパーティ情報（`partyinfo`）だけです。パーティウィンドウ（`party`）や
  近くのパーティ一覧（`nearpartyinfo`）は素のままです。
