# Boss Action Monitor

> ボスの行動を HP と残り時間で前もって知らせます

| 項目 | 内容 |
| --- | --- |
| キー | `boss_action_monitor` |
| ソース | [boss_action_monitor.lua](boss_action_monitor.lua) |
| 設定画面 | あり（アドオン一覧の歯車ボタン） |

## 使い方

ボスごとに、知らせてほしい行動を登録します。

| 種類 | 例 | 知らせるタイミング |
| --- | --- | --- |
| **HP** | 「HP 50% でシールド」 | ボスの HP がその割合を下回ったとき（1 体につき 1 回） |
| **残り時間** | 「残り 4:30 でシールド、10 秒前」 | 残り 4:40 と 4:30 の 2 回（「何秒前」が 0 なら 4:30 だけ） |

### ボスを登録する

登録のしかたは 2 通りあります。

| 方法 | 手順 |
| --- | --- |
| **名前で検索** | 設定画面の左上の欄にボスの名前を打つと、**部分一致**で候補が出ます（名前と ClassName のどちらでも当たる。50 件まで）。候補をクリックすると登録されます。候補はモンスターの表でランクが「ボス」のものだけです |
| **ターゲットから** | ボスをターゲットして「**ターゲットを登録**」を押します。ボス以外のモンスターもこちらで登録できます |

登録したら、右側で HP の件・残り時間の件を「追加」して入力します。

同じ名前のボスが難易度ごとに別の ClassName で並ぶことがあります。候補にカーソルを乗せると ClassName が出るので、それで見分けてください。

**ターゲットから登録したときは、そのときのマップも一緒に覚えます。** マップを覚えているボスは、**そのマップに入った時点から**
残り時間の知らせが動きます（ボスが出る前からレイドタイマーが動くコンテンツ向け）。
検索から登録したときはマップを覚えないので、レイドの中で「今のマップ」を押してください。「解除」で外せます。

入力欄は**打ち終えて手を止めると自動で保存**されます（Enter でも確定できます）。

### 週間ボス共通

一覧の先頭の「**★ 週間ボス共通**」は特別な 1 件で、**週間ボスレイドの中でだけ、その週のボスに効きます**。
ボスが週ごとに替わっても、「残り 1:00 で全力」のようにタイマーに沿った知らせを登録し直さずに済みます。

* HP の件も残り時間の件も登録できます。残り時間は週間ボスレイドの 7 分のタイマーです
* 特定のボスを別に登録してあれば、そのボスの件と「週間ボス共通」の件の両方が動きます
* 消せません。使わないときは件を OFF にしてください

### 残り時間の基準

| 状況 | 基準 |
| --- | --- |
| レイドタイマーが出ているコンテンツ | **レイドタイマーの残り時間**（画面のタイマーと同じ数字） |
| 週間ボスレイド | **ダメージメーターの 7 分のタイマーの残り時間**（レイドタイマーとは別の仕組み） |
| どちらも無いコンテンツ | HUD の **▶** で始める手動タイマー。長さはボスごとの「手動タイマーの長さ」 |

ゲームのタイマーが届き始めたら、手動タイマーは止めてそちらに合わせます。

### HUD

登録したボスが近くに居るとき（またはボスのマップに居るとき）に出る小さな窓です。

| 行 | 内容 |
| --- | --- |
| 1 行目 | ボスの名前 |
| 2 行目 | 残り時間と、その基準（レイド / 手動）。▶ / ■ で手動タイマーを始める・止める |
| 3 行目 | ボスの HP |
| 4 行目 | 次に来る残り時間の件 |

ドラッグで動かせ、位置は保存されます。設定の「HUD を出す」で出さないようにもできます。

### 知らせの出し方

チャット欄（システムメッセージ）には必ず残ります。ほかに次を選べます。

| 設定 | 既定値 | 内容 |
| --- | --- | --- |
| ニコチャット表示 | ON | 画面を右から左へ流れる文字で出す（自分だけ見える） |
| PT チャット表示 | OFF | パーティーチャットへ送る |
| 効果音 | ON | 知らせるときに音を鳴らす |
| HUD を出す | ON | 上の HUD を出す |

## しくみ

* 近くの敵を 0.5 秒ごとに見て、登録したボス（モンスターの ClassName で照合）の HP を読みます。
  範囲は自分から 800 です。街では動きません。
* HP の件は、**ボスを初めて見た時点ですでに下回っているものは出しません**（途中から入ったときに
  過ぎた知らせがまとめて出ないように）。倒した後（HP 0）は見ません。
* 残り時間は、素の `RAID_TIMER_UPDATE(set_time, remain_time)`（レイド）と `DAMAGE_METER_UPDATE_TIMER(frame)`
  （週間ボスレイド）が呼ばれた後に受け取ります（素の処理はそのまま）。
* 週間ボスレイドかどうかは、マップの Keyword に `WeeklyBossMap` があるかで見ています。
  残り時間が一度に 10 秒より大きく減ったとき（読み込み画面など）は、過ぎた知らせは出しません。
* ボスのマップ・見たボス・HP の印・手動タイマーは、マップを移ると捨てます。

## 保存先

`../addons/_nexus_addons_p/<アカウントID>/boss_action_monitor.json`

```json
{ "nicochat": true, "ptchat": false, "sound": true, "hud": true, "x": 400, "y": 200,
  "bosses": [ { "cls": "boss_xxx", "name": "ボスの名前", "map": "マップの ClassName", "duration": 420,
                "hp":   [ { "on": true, "pct": 50, "text": "シールド" } ],
                "time": [ { "on": true, "at": 270, "before": 10, "text": "シールド" } ] } ] }
```

`at` と `duration` は秒です（270 = 4:30）。

## 注意

* ボスは ClassName で見分けるので、**同じボスでも難易度ごとに別のモンスター**になっていることがあります。
  その場合は難易度ごとに登録してください。
* 残り時間の件は、レイドタイマーが届くコンテンツか、手動タイマーを始めたときにだけ動きます。
* 以前 weizlogy さんの HP Monitor を使っていた方へ: 設定ファイルの形が違うので、登録し直しが要ります。
